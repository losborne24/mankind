# Geographic data provenance

The globe's physical geography — landmasses, coastlines and islands — is drawn
from **Natural Earth**, self-hosted as the GeoJSON files in this directory and
served as static assets from the application's own origin.

These files are generated by [`scripts/fetch-natural-earth.mjs`](../../scripts/fetch-natural-earth.mjs).
They are committed so that `pnpm install` and `pnpm build` never need network
access. Re-run the script only to refresh the data.

## Source

| File                | Natural Earth theme        | Scale   | Used for       |
| ------------------- | -------------------------- | ------- | -------------- |
| `ne_50m_land.json`  | `ne_50m_land` (physical)   | 1:50 m  | global view    |
| `ne_10m_land.json`  | `ne_10m_land` (physical)   | 1:10 m  | regional view  |

Both are the Natural Earth **physical `land`** polygon theme, which already
includes major islands. The coastline is rendered as the **outline of the land
fill** in `map/mapStyle.ts`; no separate coastline, ocean, or boundary file is
downloaded. Per-feature attributes are stripped at fetch time (the globe renders
geometry only).

**Only physical themes are used.** No political/boundary data is fetched or
rendered, by design: a historical globe must not present modern national borders
as a default (Phase 3 supplies era-specific, evidence-backed geography).

## License, attribution & redistribution

- **Natural Earth data is in the PUBLIC DOMAIN.** Per Natural Earth's
  [terms of use](https://www.naturalearthdata.com/about/terms-of-use/): you may
  use, modify, redistribute and sell it without permission and **without any
  attribution requirement**. There are **no redistribution restrictions** — it
  is therefore safe to commit these files to this repository and ship them.
- We nonetheless credit Natural Earth as a courtesy in the on-globe attribution
  control (see `GEO_ATTRIBUTION` in `map/mapStyle.ts`).
- The conversion tooling (`martynafford/natural-earth-geojson`) is MIT-licensed;
  the *data it emits* remains Natural Earth public domain. No MIT notice needs to
  travel with the data, but the pin above records exactly where our copy came
  from.

## Cost, hosting & bandwidth

- **No paid service and no third-party runtime dependency.** The data is served
  from our own static origin, so there is no API key, rate limit, usage quota,
  or per-request cost, and no external endpoint that can rate-limit or disappear.
  (This replaces the previous `demotiles.maplibre.org` dependency, which
  MapLibre documents as development-only with no availability guarantee.)
- **Transfer is bounded and progressive.** Only `ne_50m_land.json` (~2.2 MB raw,
  ~573 KB gzip) loads at startup. `ne_10m_land.json` (~16 MB raw, ~5.0 MB gzip,
  ~3.6 MB brotli) is fetched **lazily**, the first time the user zooms to a
  regional view (just before zoom 5), and is then browser-cached and reused for
  the rest of the session — a user who stays at a continental view never
  downloads it. The only hosting cost is static bandwidth for these two files.
  **Serve both with HTTP compression** (gzip/brotli): it reduces the 1:10 m
  transfer roughly 3× and is the figure that matters for real-world cost.

## Rendering cost of the 1:10 m data

The 1:10 m `land` is 10 multipolygon features but very dense geometry (~16 MB of
coordinates). MapLibre parses it off the main thread in its GeoJSON worker, so
the fetch + parse does not block interaction, and the whole-planet fill is drawn
only at regional zoom (≥5) where the globe culls most of it to the viewport. It
is deliberately the *regional* tier, never loaded for a continental session.

## Beyond a single GeoJSON (production upgrade path)

For true close-up fidelity *finer* than 1:10 m, or to avoid shipping a single
~5 MB download at all, the next step is **vector tiles** (e.g. self-hosted
[PMTiles](https://protomaps.com/) built from Natural Earth), which serve only
the visible tiles over HTTP range requests and keep per-session transfer small.
That remains self-hosted with no paid dependency, so the cost profile above is
preserved. It is intentionally out of scope for this phase.
